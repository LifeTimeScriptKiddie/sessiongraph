# Task

This file documents the task prefix used by `sessiongraph prepare-loop`. That command appends the selected content-free SessionGraph report and writes a self-contained agentctl run directory. Produce one small, testable workflow improvement proposal. Every claim must point to a finding code or evidence event ID from the appended report.

The proposal must state the exact instruction, extension, tool, or process change; the expected metric movement; a comparable-session experiment; a rollback condition; and what would falsify the hypothesis. Do not include session transcript content.
