# Rubric

A passing proposal:

- contains `## Evidence`, `## Proposed change`, and `## Experiment`;
- cites only evidence that exists in `baseline-report.md`;
- changes one workflow variable at a time;
- defines measurable success and rollback criteria;
- preserves local-only processing and does not expose transcript content;
- avoids invented causal claims about hidden model reasoning.

Score from 0 to 1. Deduct 0.2 for each unmet criterion.
